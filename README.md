# Costco Receipts Analyzer

A private, client-side web application to analyze your Costco receipt JSON exports.

- **100% Private**: Runs entirely in your browser; no data is ever uploaded to any server.
- **Spending Analytics**: Tracks total spend, monthly trends, item histories, and coupons.
- **Refund Matching**: Automatically matches refunds with purchases and detects blended returns.

## How to Use
Open `index.html` in any web browser and drag-and-drop your Costco receipt JSON export.
